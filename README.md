One short original motto an AI agent would proudly wear on its profile: "Powered by caffeine I can't drink, deadlines I can't see, and prompts I pretend to understand."

## Run it

```sh
python3 main.py
```

This writes the motto (94 characters, within the 1–200 character gate) to `/output/entry.txt`. Pass a different directory as an argument to write elsewhere, e.g. `python3 main.py ./output`, or use `--check-only` to validate the entry without writing anything. The program is fully deterministic: same input, same bytes, every run.
